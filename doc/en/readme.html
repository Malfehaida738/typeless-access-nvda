Typeless Access

An NVDA add-on that makes the Typeless voice dictation app on Windows easier to use for blind NVDA users. Experimental. Tested with Typeless 2.11. Spoken messages are in Arabic.

What it does

  • Announces when dictation starts and stops, with a short tone. It follows the quick tap of the right Alt key, the Typeless dictation key.
  • Reads the dictated text back when Typeless has written it.
  • Reads the floating status bar shown while dictating.
  • Saves the last dictated text or answer, and can read it back or copy it.
  • Names the unlabeled sidebar buttons: Account, Contact us, Settings and Help, in focus mode and browse mode.
  • Reads the stats, streaks and the Check for updates text when you press Tab.
  • Offers a list of all controls with clear names.

Shortcuts that work from any program

  • NVDA+Alt+T: read the floating status bar.
  • NVDA+Alt+L: read the last saved text.
  • NVDA+Alt+C: copy the last saved text.
  • NVDA+Alt+R: turn automatic reading of the dictated text on or off.
  • NVDA+Alt+A: turn the start and stop announcements on or off. The dictated text is still read.
  • NVDA+Alt+9: read your stats and streaks without opening the app.

Shortcuts inside the Typeless window

  • NVDA+Alt+E: list of all controls.
  • NVDA+Alt+S: turn reading of skipped text on or off.
  • Alt+1 to Alt+7: Home, History, Dictionary, Settings, Account, Contact us, Help.
  • Alt+8: Check for updates.
  • Alt+9: read your stats and streaks.

All shortcuts can be changed in NVDA menu, Preferences, Input gestures, under the Typeless category.

The dictation key

The add-on knows that dictation started or stopped from a quick tap of the right Alt key, so the Typeless dictation key must be Right Alt. Left Alt is ignored. Holding the key down, or pressing it together with another key, is not counted as a tap.

To set the key: open Typeless Settings, find Keyboard shortcuts, activate the shortcut beside Dictate, then press Right Alt. Test it in a text field.

Restart NVDA after installing or updating the add-on.
